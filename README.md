# hxwl-06 显微镜玻片观察 · 切片复核闭环

登记 → 批次放行 → 判读 → 复核版本链 → 重染冻结，全链路留痕的切片复核闭环。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 闭环规则

- **登记**：每张切片登记编号、部位、厚度、染色批次、封片时间。
- **判读门槛**（缺一不可，否则不能判读/复核）：
  - 厚度在 2–8 μm；
  - 封片固化满 24h；
  - 染色批次已放行。
- **复核**：必须填写原因，只追加新版本（v1、v2…），旧版本原值保留。
- **重染**：自动新建批次（未放行）、冻结原结论、重设封片时间、切片回到待判读。
- **同批联动**：批内出现不合格切片时，其余切片自动转入待复核。
- **一致性**：状态持久化在 localStorage，刷新后切片、批次、复核状态与版本链一致；
  审计规则 R1–R6 持续校验，冲突按「编号 / 批次 / 原值 / 触发规则」列出。

## 审计规则

| 规则 | 内容 |
| --- | --- |
| R1 | 已判读切片厚度须在 2–8 μm |
| R2 | 已判读切片封片须满 24h |
| R3 | 已判读切片所属批次须已放行 |
| R4 | 同批出现不合格时其余切片须为待复核 |
| R5 | 重染后旧批次下的结论须冻结 |
| R6 | 版本链须从 v1 连续递增 |

## 代码结构

- `src/domain.ts`：领域模型、判读门槛、审计与状态迁移（纯函数）
- `src/App.tsx`：页面与交互（登记表单、台账、版本链、批次、冲突清单）
- `src/verify.ts`：闭环规则验证脚本

验证规则：

```bash
./node_modules/.bin/tsc src/domain.ts src/verify.ts --outDir /tmp/verify \
  --module commonjs --target ES2020 --strict --esModuleInterop --skipLibCheck
node /tmp/verify/verify.js
```

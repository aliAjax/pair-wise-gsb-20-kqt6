# hxwl-06 显微镜玻片观察 · 切片复核闭环

切片登记 → 判读门槛校验 → 复核版本链 → 不合格整批牵连，全程可追溯。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5106

## 复核闭环规则

| 规则 | 内容 |
| ---- | ---- |
| R1 | 切片厚度须介于 2–8 μm（登记与判读均校验） |
| R2 | 封片须满 24 小时方可判读 |
| R3 | 染色批次须为已放行状态 |
| R4 | 同批出现不合格切片，其余切片自动转入待复核 |
| R5 | 重染须新建染色批次，原判读结论即时冻结 |
| R6 | 复核只能生成带原因的新版本，旧版本全部保留 |

## 功能

- 切片登记：编号自动生成，登记部位、厚度、染色批次、封片时间
- 判读门槛：厚度 / 封片时长 / 批次放行三重校验，未达标列出命中规则
- 复核版本链：每次复核生成带原因的新版本，旧版本保留可查
- 不合格处理：批次隔离、当前结论冻结、同批其余切片转待复核
- 重染：自动新建批次（记录替换关系）并登记新切片，原结论冻结
- 冲突记录：状态变更列出切片编号、批次、原值、新值与触发规则
- 持久化：状态写入 localStorage，刷新后切片、批次、复核状态与版本链一致
- 演示时钟：可 +6h 推进，用于演示封片时长门槛；可一键重置演示数据
